# LinkSMM — SMM & Digital Services Marketplace HTML Template

LinkSMM is a clean, responsive HTML template for social media marketing agencies, digital service marketplaces, consultants, personal-branding teams, and campaign specialists. Its marketplace-style service presentation makes it suitable for a future WordPress and WooCommerce conversion while keeping the submitted product framework-neutral and easy to customize.

## Key features

- 20 carefully designed HTML pages
- SMM and digital-service marketplace presentation
- Social media management, profile optimization, lead generation, personal branding, content marketing, outreach, audits, scheduling, and community-management services
- Service archive and single-service layouts
- Pricing, cart, checkout, order-success, and customer-dashboard screens
- Blog archive and article-detail pages
- Combined login and registration interface
- Responsive WordPress-compatible three-level menu markup
- Mobile drawer with close button, submenu controls, backdrop closing, and Escape-key support
- FAQ accordion, service filters, search overlay, gallery, quantity controls, and tabs
- Bootstrap 5 grid and Bootstrap Icons
- Vanilla JavaScript with no jQuery dependency
- Organized SCSS source and compiled CSS
- Responsive, keyboard-friendly interface
- Detailed buyer documentation and source credits

## Included pages

Home, About, Shop, Service Details, Pricing, Bulk Order / Quote Request, Cart, Checkout, Order Success, Login / Register, Dashboard, Blog, Blog Details, FAQ, Contact, Delivery Policy, Refund Policy, Privacy Policy, Terms, and 404.

## Important disclosure

LinkSMM is a static front-end HTML template. WordPress, WooCommerce, authentication, payment processing, databases, and form-delivery services are not included. The downloadable package uses redistribution-safe SVG placeholders. Preview-only AI-generated images are not included in the customer ZIP.
