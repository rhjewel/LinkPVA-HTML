# LinkSMM — SMM & Digital Services Marketplace HTML Template

LinkSMM is a responsive static HTML template for social media marketing agencies, digital service marketplaces, consultants, and campaign teams.

## Included

- 21 HTML pages with two homepage variations
- Responsive three-level navigation
- Service shop, service details, pricing, cart, and checkout layouts
- Blog listing and article layouts
- Login/register tabs and customer dashboard
- FAQ, contact, quote request, policy, success, and 404 pages
- SCSS source and compiled CSS
- Custom JavaScript interactions with jQuery, Bootstrap, Popper, and Swiper assets included

## Quick start

Open `index.html` directly or serve the directory through a local web server:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173/`.

## Important

This is a front-end HTML template. Authentication, payments, form delivery, database storage, WordPress, and WooCommerce are not included. Connect the interfaces to your preferred backend before production use.

Images in the hosted demo are preview assets. Do not place AI-generated preview images in an Envato download package. Replace them with assets for which you hold redistribution rights or with distribution-safe placeholders.

Full documentation is available at `documentation/index.html`.
